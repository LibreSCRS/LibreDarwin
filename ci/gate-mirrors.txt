# gate-mirrors.txt — which gate scripts are the same file in more than one
# repository, and which pairs differ on purpose.
#
# Format:   <path>  SAME:<repo>[,<repo>…]       <why it is mirrored>
#           <path>  DIFFERENT:<repo>[,<repo>…]  <why it may differ>
#           <path>  PENDING:<package>           <who creates it, and when>
#
# A drift scan compares them from a checkout holding every repository side by
# side, the only place they all exist at once. Both directions fail:
# a SAME row whose copies differ, and a DIFFERENT row whose copies have all
# become identical -- the second is a deleted decision, and it looks like a
# cleanup. A PENDING row passes while the file exists nowhere and fails the
# moment it exists anywhere, so it cannot become a permanent amnesty.
#
# An empty reason fails.

# --- different on purpose ----------------------------------------------------
ci/scripts/abi-snapshot.sh  DIFFERENT:LibreMiddleware,LibreAgent  Two surfaces, not two copies of one: the middleware snapshots seven shared libraries against a recorded public ABI, the agent snapshots a single component and refuses a different set of empty shapes. Merging them would lose whichever set of guards the loser had.
ci/scripts/abi-snapshot.selftest.sh  DIFFERENT:LibreMiddleware,LibreAgent  Proves two different surfaces, so it is two different proofs; the middleware copy asserts guards the agent copy has no artefacts for.
ci/scripts/check-cleansing-deleters.sh  DIFFERENT:LibreMiddleware,LibreAgent  Two policies, not two copies: the middleware keeps a file of exemptions for deliberate non-cleansing deleters and the agent deliberately has none. A merge would silently adopt one policy for both, and the comment recording the difference is the first thing such a merge deletes.
ci/scripts/check-cleansing-deleters.selftest.sh  DIFFERENT:LibreMiddleware,LibreAgent  Proves two different policies, including the exemption file one of them does not have.
packaging/arch/check-recipe.sh  DIFFERENT:LibreMiddleware,LibreAgent,LibreKDE,LibreLinux  Each recipe check names its own package and its own spec file; there is no shared spelling to converge on, and a merge would check one package four times.
packaging/arch/check-recipe.selftest.sh  DIFFERENT:LibreMiddleware,LibreAgent,LibreKDE,LibreLinux  Proves four different recipes against four different packages.
